DRS Fraud & Operational Intelligence Module

Recykal (Rapidue Technologies) · Deposit Return Scheme · In Active Development
Problem

A national Deposit Return Scheme (Poland's Kaucja system) processes millions of container-return transactions with no layer watching for fraud patterns across the full lifecycle — fake barcodes, tricked sensors, ghost products, and organized rings currently go undetected because nothing analyzes the data across transactions and time.

Solution

Researched and defined 19 canonical fraud scenarios with real detection logic and thresholds, fact-checked line-by-line against real Kaucja.pl / GS1 Polska sources rather than accepted at face value. Directed the build of a Python-based data simulator that generates realistic transaction data with injected, ground-truth-labeled fraud cases, so the detection engine can be benchmarked for precision and recall before it goes live.

Outcome

A validated 19-scenario fraud library with a locked Milestone 1 scope (7-scenario Product & Barcode Intelligence Engine), plus a working simulation & benchmarking tool to test it against. Finance module for the same platform is just getting underway.

Recykal Flowchart Studio

Internal Engineering Tool · Node.js & Express · MCP Server
Problem

At a ~100-person eng/product team, no single place shows how a process step, a system, a DB table/column, and a code function connect — so every change means re-reading everything from scratch, and diagrams in Miro/wikis go stale the moment nobody remembers to update them.

Solution

Designed and built an internal architecture-governance platform (Node.js, Express, vanilla JS frontend) with a linked map (map.json) connecting Business Process → Systems → Database Schema → Code, a Quality Engine that blocks on orphan steps/cycles/missing links, and forward & reverse Impact Analysis. An MCP server exposes ~12 tools so an AI agent can query the map directly & write updated links back as a byproduct of finishing the task — not a separate chore a human has to remember.

Outcome

A queryable, AI-consumable architecture map with 13 automated regression suites and a drift-check script, closing the human-remembers-to-update-it failure point that makes most CMDB/service-catalog tools decay.

Outcome Metric

AI-Consumable Architecture Map
map.json Linked Map · Quality Engine · Impact Analysis · MCP Server

Every node (process step, system, DB table/column, code file/function) has a stable ID linked to the layer above/below it. A Quality Engine blocks on duplicate IDs, orphan steps, cycles, and missing owners. Before a change ships, forward impact ("what does this touch") and reverse impact ("what touches this") can be queried directly. A local backend (server.js) supports multi-project use, password-locking, and versioned upload/export — all backed by plain git-diffable files. The MCP server (mcp-server.js) lets Claude or any AI IDE list projects, get business flow, run impact analysis, and apply a mapped code change, with 13 regression test suites plus a drift-check script verifying the map hasn't gone stale against real code.
